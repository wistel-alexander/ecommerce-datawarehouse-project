# Ecommerce Data Warehouse Project

Proyecto ETL y Data Warehouse utilizando:
- Python
- Pandas
- SQL Server
- Data Warehouse
- Modelo Estrella


Para que este proyecto se ejecute en otra computadora, normalmente se necesita:

Python 3.10 o superior
Git para clonar el repositorio o carpeta con el proyecto: "https://github.com/wistel-alexander/ecommerce-datawarehouse-project.git"
SQL Server instalado y funcionando localmente
ODBC Driver 17 para SQL Server
Entorno virtual de Python
Dependencias del proyecto instaladas con: pip install -r requirements.txt
Base de datos llamada EcommerceDW creada en SQL Server
Ejecutar el proyecto desde la raíz con: python -m etl.run_etl
Requisitos técnicos del proyecto:

Python
Pandas
SQLAlchemy
pyodbc
python-docx
kagglehub
tabulate
Importante:

El proyecto está diseñado para trabajar con SQL Server, no con SQLite ni MySQL.
La conexión está configurada para usar localhost y la base de datos EcommerceDW.
